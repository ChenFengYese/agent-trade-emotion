# 72 小时纸面交易中文记录附加要求 v1

本附加要求只负责把已经提交的纸面交易工件导出为中文审计文档，不改变冻结理论、行情分析、交易决策、风险门、纸面撮合或 72 小时运行状态。

每次自动任务唤醒时必须：

1. 在创建新周期前，执行：

   ```bash
   /opt/homebrew/bin/python3.12 -m trade_system.theory_paper.zh_record \
     --run-dir .runtime/theory-paper-v1/current --all
   ```

   这一步补齐并校验所有已提交周期的中文文档。没有已提交周期时可以继续正常首轮流程。

2. 当轮 `theory-paper-submit` 成功后，再次执行同一命令。只有命令退出码为 0、返回的周期数等于已提交决策周期数、且每条记录都给出路径和 SHA-256，才算当轮记录完成。

3. 每轮文档必须写入：

   `.runtime/theory-paper-v1/current/reports/zh/`

   文件名使用该轮实际执行提交时间的北京时间、周期 ID 和 Agent/轮次编号；不得用自动任务唤醒时间冒充决策时间。

4. 文档至少完整覆盖：

   - 冻结输入、数据质量、全部多尺度指标和 `D/L/C/F/R/K` 测量；
   - 结构位置、全部候选几何、全部竞争路径、支持与冲突证据；
   - 冻结 thesis、替代假说、支持/否证谓词、到期与下一观测；
   - 当前行动或不行动、止损止盈、仓位、风险门和机会成本；
   - 盘中撮合、情绪扰动、Agent 动作、逐项执行回执和提交后组合状态；
   - 冻结理论文件版本与摘要、决策环节到理论章节的映射、公开理论/数据来源及适用边界；
   - 事务摘要、账本事件、原始工件路径、文件 SHA-256 与事务绑定摘要。

5. “完整推理链路”按可审计的“输入—规则—判断—动作—结果—来源”记录；不得声称、伪造或要求模型私有的逐 token 隐藏思维。未写入冻结工件的理由必须标为不可追溯，不能事后补造。

6. 中文文档是 write-once sidecar。若同名文档已存在，只有内容逐字一致才允许成功；内容不一致、摘要不匹配、账本无对应提交事件或任一原始工件缺失时必须失败关闭并在当前任务中报告，不得修改历史交易工件来适配报告。

7. 中文记录导出失败不能用来改变当轮市场判断或重写已提交决策；修复范围只限记录导出器或自动任务提示词。
