### 三、Agent 的分析自由

分析空间默认开放，不受固定指标白名单限制。只要数据点时可得、来源可追溯、公式可复算、质量和成本明确，Agent 可以主动请求并组合：

- Bollinger Bands、bandwidth、`%B`、squeeze/expansion；
- rolling/session/anchored/event VWAP；
- ATR、实现波动率、EMA、ADX、趋势效率；
- 成交量分布、相对成交量、订单流/CVD proxy、spread、深度和冲击；
- OI、funding、basis、拥挤、跨市场相对强弱；
- 合规公开事件和新闻元数据；
- 其他能够区分竞争路径的公开或已授权观测。

指标只是辅助观测，不是机械买卖规则。每个新增观测只需说明：它在区分什么路径、适用什么时间尺度、改变哪个前提、有什么局限。缺失数据保持 `UNKNOWN`；可以保留多条有标签的推论路径，但不得把推论冒充观测事实。

### 四、仅保留必要硬边界

硬边界只覆盖：

- 禁止前视、后见调参、伪造数据和把缺失补成零；
- 点时截止时间、数据来源、质量与可复算性；
- 账户/单标的最大风险、组合最坏损失、杠杆、保证金和极端风险；
- 陈旧数据、冲突状态、保护失败和停机；
- paper/live、账户、凭据、订单、资金及外部写入授权。

风险内核可以拒绝不可行动作，但不能以“谨慎”为由静默删除可行的持有、加仓或重入动作。`ABSTAIN/WAIT` 必须给出具体的数据缺口、风险 veto 或相对效用理由；空仓和错失机会不能被当成零成本。

### 六、默认研究路线

除非只读核验发现事实不成立，按以下顺序推进：

1. **现实映射**：列出现有市场数据、情绪/行为代理、战略状态、风险/账本和 Agent 输入的真实调用链；明确哪些旧实现已经替 Agent 预设市场解释、路径和动作，并先退役这些错误决策中心。
2. **V1 历史研究基线**：按原始时间顺序只读 V1 当时可得记录，让 Agent 自主分析多时间尺度结构、depth/aggTrades、OI、funding、ratio、premium、价格行为和其他已有证据；由 Agent 构造竞争路径、识别需要的补充计算，并比较连续仓位动作。不要先写 runner 或固定指标清单。
3. **硬边界复算**：把 Agent 提出的持有、试探建仓、加仓、减仓、退出、重入或等待方案交给现有确定性风险、成本和账本组件复算；只返回具体硬 veto 和数值后果，不用确定性指标规则替 Agent 做策略选择。
4. **先证明分析与动作可区分**：在任何新连续 runner 或未见冻结实验前，先证明 Agent 确实使用了情绪/行为证据、维护了上一战略状态，并至少产生一个不是固定 WAIT/HOLD 回退、也不是预筛集合复述的仓位判断；否则继续做市场研究或报告数据阻塞，不扩张工程。
5. **事前冻结实验**：上述能力成立后，才选择新的连续未见窗口，冻结输入、对照政策、风险、成本、评价和停止条件；动作空间由持仓与硬风险决定，不由固定指标阈值决定。
6. **同条件对照与原始结果**：静态 V1 baseline、简单确定性占位政策和 Agent 动态政策使用相同 PIT 数据、风险和成本；先完整运行并封存原始结果，再审计和提出下一版本修改。

- 每个动作可追溯到 Agent 构造的路径、证据、风险、成本和硬边界可行集合；固定三路径、固定指标交易规则和预筛动作排序器不满足验收；
