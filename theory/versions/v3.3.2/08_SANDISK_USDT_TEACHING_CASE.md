## 2. 标的口径

用户称标的为“闪迪USDT”。外部评价以NASDAQ SNDK正股验证，并引用SNDKx代币化股票作方向映射。

已核查公开说明：

- Kraken将SNDKx描述为由真实SNDK股票1:1抵押的代币化股票；
- SNDKx提供对底层股票价格变化的间接敞口，不等同于直接持有SNDK股票；
- 持有人不因此取得底层股东权利；
- SNDKx可24/5交易，传统股票具有不同交易时段；
- 因此SNDK方向可作合理参照，但代币venue的盘外流动性、spread、basis、费用和价格口径不能省略。

来源：Kraken [`SNDKx产品说明`](https://www.kraken.com/xstocks/sndkx) 与 [`xStocks FAQ`](https://support.kraken.com/articles/xstocks-faq)。

## 3. 原始市场认知的核心

### 3.1 高周期

- 历史高点约2373.96，当前约1448.44；
- 高点以来形成明显下降区间；
- 1310低点后的上涨被识别为下降趋势中的反弹，而不是新上升周期；
- 反弹后剧烈下跌但尚未创新低，说明市场处于“反弹结束/下行恢复”与“下跌中震荡”的转换区。

### 3.2 关键区域1300/1310

- 1310附近在此前上涨周期和整数关口上具有高可见性；
- 当地量价表现被解读为充分博弈和响应性买盘；
- 该区域更偏技术、成本和反身性支持，而非已确认基本面价值锚；
- 第一次测试可能触发防守与反弹；
- 若防守流动性被消耗并出现接受性跌破，市场可能重新定价并加速向更低区域。

### 3.3 人群与心理假说

用户提出：

- 前期套牢盘在反弹中寻求解套；
- 1310附近抄底盘随反弹兑现；
- 恐慌、贪婪和解套“饥渴”并存，恐慌占优；
- 公司或机构可能维护1300、吸收筹码并配合利好派发；
- 利好是积压情绪的放大器，不必然意味着基本面逆转；
- 错误叙事亦能产生真实订单和自我实现反馈。

V3.3.2保留这些内容，但按 `Observed → Latent State → Actor → Intent` 分层。

### 3.4 原始路径

核心状态路径可重写为：

```text
下降周期
→ 1310附近支撑争夺和短反弹
→ 反弹衰竭/供应恢复
→ 再测试1300
→ 1300接受性失守
→ 恐慌/流动性负反馈和下行扩张
→ 低位筹码重新配置
→ 较大反弹
→ 高位供应与反弹衰竭
→ 再度下跌或震荡
```

这一状态链比“未来某天精确到某价”更接近原分析的真正优势。

## 7. 状态机教学重写

### S0：高周期下降、低周期反弹

观察：高点下移、现价远低于历史高位、1310后反弹。

竞争解释：下降中修复；新上升周期开始；事件性短挤压。

### S1：1300支撑争夺

事件条件：价格接近1300、波动和成交扩大、首次拒绝下破。

参与者假说：套牢者等待反弹、抄底者参与、响应性买盘、机构维护候选。

动作含义：不能只因“支撑”追高；观察反弹效率、成交和下一次测试。

### S2：反弹衰竭

事件条件：上冲后无法接受新高、宽幅震荡、收盘弱、供应重复出现。

参与者假说：解套/获利了结、自然卖压、派发、做市库存、利好兑现。

### S3：支撑失效与下行扩张

事件条件：1300被有效跌破，价格不能快速收回，反弹弱化。

机制：支撑流动性消耗、止损/强平/趋势流可能形成反馈。

动作含义：关闭“1300立即防守成功”路径；下调目标区域并保护反弹空头或退出逆势多头。

### S4：低位再配置与反弹

事件条件：约1000区域出现卖压衰减、下破拒绝、量价/flow改善或事件催化。

机制：空头回补、价值/反转资金、筹码重新配置、强平尾声。

### S5：反弹接受或再次衰竭

若站稳关键压力并形成新价值区，进入更大反弹；若上冲供给增加、动能和流效率下降，则回到下跌中震荡/再次下跌。

## 10. 教学结论

用户方法的优势更接近：

> 多尺度市场状态识别 + 参与者约束假说 + 条件路径推演 + 状态转换预测 + 动态证伪。

方向、状态转换和关键区域在该案例中表现强；精确时间、部分目标和成交量判断存在真实不足。正确的理论改进不是删除主体假说，也不是把所有内容变成指标打分，而是：

1. 保留多假说与提前规划；
2. 分层记录事实、状态、主体和意图；
3. 优先预测事件顺序；
4. 将timing作为独立模型；
5. 分别评价方向、路径、价位、时间、机制、动作和仓位；
6. 用未来样本判断可迁移性。

## 11. 动态交易与仓位管理的教学重构

本节是 candidate.3 依据原市场推理做的**事后理论重构**，用于展示当时若采用完整动态合同应如何写。它不是用户当时的逐笔原文，不代表用户实际持有、下单、成交或获得这些收益；所有账户与 fill 均为 `UNKNOWN/NOT_AVAILABLE`。

### 11.1 先建立 episode，而不是直接报仓位

```text
StrategicEpisodeState
  thesis: 高周期仍是下降；关键支撑失效后可能下行扩张
  horizon: 日线/多日 event clock
  key zones: 1300附近、其下更低价值区、反弹压力区
  hard invalidation candidate: 价格接受更高价值区且供应衰减
  status: WATCHING or ACTIVE，由当时精确原文确认；当前教学记录不足

ReferenceExposureState
  UNKNOWN_ACCOUNT
  reference branches: FLAT / prior long / prior short 均需原工件确认
```

市场看空不等于已经做空；账户有空仓也不等于市场观点中性。先分开这两个状态，后续动作才不会被故事替代。

### 11.2 状态—角色—动作链

| 市场状态 | 参考前态 | 条件动作与目标态 | 风险/取消条件 |
|---|---|---|---|
| S0 高周期下降、局部反弹 | FLAT或既有风险未知 | 战略 bearish episode 保持；未到好几何可 `WATCH/WAIT` | 说明机会成本和下一关键区 |
| S1 首次测试1300并拒绝下破 | 仅在FLAT分支 | 可考虑小型 `TACTICAL/PROBE LONG`，不是战略翻多 | 接受性跌破立即取消；probe有独立小预算和到期 |
| S2 反弹进入压力且买入效率下降 | TACTICAL long | `HARVEST/CLOSE` tactical；若上冲失败被确认，再评估 bearish `OPEN` | 不能在同一含糊bar假定先卖最高再反手；路径不明则不评价fill |
| S3 1300接受性失守、下行扩张 | bearish CORE或FLAT | CORE可 `HOLD`；只有新证据和整体预算允许才 `ADD` | 快速收回并接受1300上方、流动性反转或数据失效触发复核/减险 |
| S4 约1000低位卖压衰减/再配置 | profitable bearish CORE | `HARVEST` 主体风险，独立 `RUNNER`；必要时 `CLOSE` 并进入 `REENTRY_PENDING` | runner独立giveback；不因看空故事无限持有 |
| S5 反弹接受或再次衰竭 | FLAT/RUNNER | 接受高位则关闭/失效 bearish episode；反弹衰竭且有新证据才 `REENTER` bearish | reentry重新计算风险；若新上升状态成立则是新 bullish episode |

这条链允许“战略看空 + 局部反弹多头 probe”共存，但两者角色、期限、失效和预算必须独立。TACTICAL 盈亏不能静默改写 CORE thesis；反向操作也不是一个原子 `REVERSE`。

### 11.3 风险预算示例（无真实数量）

```text
R_active CORE
+ R_TACTICAL_if_activated
+ R_RUNNER
+ R_pending_reentry_if_jointly_activated
+ gap/liquidity/basis stress
<= Agent-declared reference episode/portfolio budget
```

若 TACTICAL 多头与 CORE 空头同时存在，应说明它们是在交易不同 horizon、做 hedge，还是仅仅自相矛盾。不能只净额后声称风险变小，因为 basis、时钟和两套 stop 仍可能同时造成损失。

## 13. 参考执行与代币化产品限制

即使 SNDK 正股后来进入某个价格区，也不能直接说 SNDKx/USDT 订单成交：

1. 正股与 token 的交易时段、venue、spread、basis 和深度不同；
2. 正股日线 high/low 只证明底层路径，不能证明 token 在同一时刻和价位可成交；
3. stop/limit 触发、partial fill、fee、滑点、funding/borrow 和汇率口径未知；
4. 公司行动、发行/托管/赎回与追踪误差可能改变两者关系；
5. 当前案例只能用 `TOUCH_ONLY_UPPER_BOUND` 或明确的公开参考价模式，真实执行为 `NOT_APPLICABLE`。

因此，本案例能验证的最高层级是市场状态和条件路径，部分参考动作可做教学评价；动态仓位转换、执行质量和账户收益尚无完整证据。

## 14. Candidate.3 从案例吸收的具体修正

1. 保留用户的主体/意图假说，但把真正的风险激活绑定可观察状态；
2. 将“方向预测”和“战略episode”分开，避免短周期反弹自动推翻高周期观点；
3. 将线性价格序列改为 event-clock activation chain；
4. 将入场、早期落袋、路径目标、失效和再入场分开；
5. 明确 current exposure、target exposure 和 delta，未知持仓不猜测；
6. 只在新证据与风险预算共同成立时ADD，不以价格更低为理由；
7. 触价、参考执行和真实fill分层；
8. 未来按市场、动作、仓位、转换、执行、风险和机会成本独立复盘。

这些修正保存了案例中经用户和后续路径支持的状态转换能力，同时把时间误差、成交量错误、主体不可验证和执行证据缺失保留下来，没有用后见之明把案例改写成“全部准确”。
