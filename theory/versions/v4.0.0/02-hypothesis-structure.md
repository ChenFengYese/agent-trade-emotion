# V4.0 Hypothesis and Structure Engine

Each case maintains a leading mechanism, strongest alternative, and `OTHER`. For each hypothesis record support, contradiction, unknowns, falsifiers, and the next observation that would change the ranking.

Use probability bands or ordinal ranking unless calibration exists. The required operation is `Prior → Evidence → Update Direction → New Band`, not pseudo-precise probabilities.

Structural events must specify timeframe and confirmation semantics. Breakout/breakdown should distinguish penetration, acceptance, and reclaim/failure. Rejection should distinguish micro rejection, structural rejection, and confirmed rejection. Swing points should use a declared minimum swing threshold such as a volatility-scaled rule, not narrative labels alone.

Range-to-expansion is an explicit state transition. A single wick is not automatically a regime change. Conversely, repeated dismissal of a valid expansion must not be used as a permanent excuse to ignore new evidence.
