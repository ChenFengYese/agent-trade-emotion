# MSTA-HED 研究系统理论候选 v1.0

状态：`E0_THEORY_AND_MEASUREMENT_DESIGN_ONLY`

权威关系：本文件是独立版本的理论候选，不修改、不替代、也不自动晋升
`CORE_TRADING_THEORY_v2_1.md`。任何市场有效性、预测能力、收益能力、paper
或实盘结论，必须经过后续独立阶段门和相应数据验证。

## 1. 研究对象与核心命题

本项目要构建的不是“若干指标投票后预测涨跌”的程序，而是：

```text
点时可用数据
→ 多周期状态识别
→ 结构位置与可交易性
→ 有限路径和机制假说
→ 去重后的证据更新
→ 条件触发与期望值判断
→ 风险约束执行
→ 结果归因、校准与理论修订
```

系统的首要目标不是每次预测正确，而是让每个结论都能回答：

1. 当时实际知道了什么；
2. 哪些只是测量或推断；
3. 同时保留了哪些竞争路径；
4. 什么证据会支持、削弱、终止或使假说过期；
5. 什么条件满足后才允许从市场判断转换为交易；
6. 失败属于数据、测量、状态、机制、参数、行动几何还是执行；
7. 如何以一个局部、可归因的变化生成下一版本。

## 2. 证据声明边界

本候选的最高正面声明仅为：

> 已形成一套可测量、可反证、可版本化、可用历史数据验证的研究方法候选。

本候选不声称：

- 市场可以被稳定预测；
- RSI、K 线、订单流、情绪或宏观变量具有已证实的交易优势；
- 任一评分已经是真实概率；
- 任一历史回测已经支持本候选；
- 系统已经可以 paper、部署或参与实盘交易。

证据状态统一为：

| 状态 | 含义 |
| --- | --- |
| `CONFIRMED_CONSTRAINT` | 由定义、数学约束、官方语义或已复现合同事实确认 |
| `TEMPORARILY_SUPPORTED` | 有相关文献或局部事实支持，但尚未在目标市场、周期和成本下验证 |
| `QUEUED_HYPOTHESIS` | 有研究价值且已具备测量方向，等待数据或实验 |
| `WEAK_EVIDENCE` | 数据或测量不足，不能形成支持或失败结论 |
| `CONTRADICTED_VERSION` | 当前版本受到足量反证，但保留并进入错误归因 |
| `FALSIFIED_VERSION` | 预注册硬反证条件在合格证据上成立；仅终止该版本 |
| `INCONCLUSIVE` | 缺口、功效、覆盖、口径或执行问题使结果不可判定 |
| `ARCHIVED` | 历史版本永久留存，不参与当前排序 |

## 3. 七类对象必须分离

### 3.1 事实

事实是能够从具有来源身份、时间身份、修订身份和完整性身份的数据直接读取的
记录，例如某时刻的成交价、订单簿更新序号或官方事件发布时间。

### 3.2 测量

测量是由冻结公式从事实计算出的量，例如 ATR、ER、RVOL、CLV、RSI 分位、
区间位置或订单流不平衡。测量不是机制解释。

### 3.3 状态信念

状态信念是对不可直接观测市场状态的有限估计，例如“日线下降、4 小时反弹、
1 小时转换候选”。状态必须允许 `UNKNOWN` 与 `ABSTAIN`。

### 3.4 机制假说

机制假说解释市场行为为何出现，例如新增多头、空头回补、去杠杆、库存调整、
被动吸收或消息冲击。多个机制可以同时存在，不能强迫互斥。

### 3.5 路径假说

路径假说描述未来一段时间内可区分的价格—状态路径，例如延续、平衡、转换、
事件性挤压、流动性真空。参与同一决策窗口的路径应尽量互斥，并保留
`OTHER`、`UNKNOWN`。

### 3.6 交易假说

交易假说把一个路径、结构位置、触发条件、成本和失效条件绑定起来。市场路径
判断正确，不等于当前交易值得执行。

### 3.7 行动与结果

行动是 `WAIT/WATCH/PREPARE/EXECUTE/MANAGE/EXIT/SUSPEND` 之一。结果包括
路径结果、触发结果、成交结果、费用、MFE、MAE、风险和执行偏差。结果不能
反向改写当时的事实或假说。

## 4. 点时信息集与因果时钟

对决策时刻 \(\tau\) 和研究通道 \(l\)，可用信息集定义为：

\[
\mathcal I_l(\tau)=
\{x_i \mid available\_at_i\le\tau,\ lane_i=l,\ quality_i\in\mathcal Q_l\}
\]

变量：

- \(x_i\)：一个带来源、修订、事件时间和可用时间的数据对象；
- `event_at`：经济或市场事件实际发生时间；
- `published_at`：来源首次发布该值的时间；
- `available_at`：研究系统在该通道可以获得该版本的最早时间；
- `ingested_at`：系统实际接收时间；
- `revised_at`：新修订版本可用时间；
- \(\mathcal Q_l\)：该通道允许的数据质量集合。

设计依据：回测只能使用当时可获得的版本，不能使用事后修订值、未来补全值或
最终版分类。

适用条件：数据必须具有足够的时钟语义；若来源只能提供事件日期而无法提供
发布时间，则相应数据只能进入低频、保守延迟或 `UNKNOWN_PIT` 通道。

验证方法：

- 对每条记录检查 `event_at ≤ published_at ≤ available_at ≤ decision_at`；
- 对修订数据保留全部版本，禁止原地覆盖；
- 使用历史快照或 vintage，而非当前最新值回填历史；
- 任一时钟未知时，相关特征必须 `ABSTAIN`，不能默认为零。

## 5. 多周期状态模型

### 5.1 固定职责

| 周期 | 职责 | 禁止事项 |
| --- | --- | --- |
| 周线 | 长期背景、历史主区域、长期波动 | 直接生成低周期订单 |
| 日线 | 主导方向与 5–20 日状态 | 被一次 15 分钟信号推翻 |
| 4 小时 | 当前阶段与允许策略族 | 单独决定精确成交 |
| 1 小时 | 交易结构、候选失效点与入场区 | 改写日线背景 |
| 15 分钟 | 最终触发与订单优化 | 把 RSI 超卖等同于反转 |

这是一项方法约束，而不是已验证的最佳周期组合。后续应比较简化基线，例如
只使用日线+1小时，检验增加周期是否真的改善样本外结果。

### 5.2 状态向量

\[
S_t=(B_t,E_t,X_t,Q_t)
\]

其中：

- \(B_t\)：背景方向，取 `UP/DOWN/BALANCE/UNKNOWN`；
- \(E_t\)：阶段，取 `IMPULSE/PULLBACK/BALANCE/EXHAUSTION/TRANSITION/UNKNOWN`；
- \(X_t\)：可观测状态轴；
- \(Q_t\)：数据质量、覆盖、时钟与不确定性状态。

建议的可观测轴为：

\[
X_t=(D_t,L_t,C_t,F_t,R_t,K_t,Z_t)
\]

- \(D\)：方向与结构；
- \(L\)：杠杆、持仓和拥挤；
- \(C\)：订单流或成交压力；
- \(F\)：强平、被动去杠杆和强制流；
- \(R\)：冲击后的韧性、吸收或补充；
- \(K\)：事件、宏观和跨市场背景；
- \(Z\)：结构区域与当前位置。

任何轴缺失都必须保留为未知，禁止把“未观测到”解释为“不存在”。

### 5.3 状态滞回

为避免单根 K 线导致状态来回切换，候选状态 \(s'\) 只有在连续满足进入条件
\(m\) 次或累计证据超过进入阈值后才替换当前状态 \(s\)；退出使用不同阈值：

\[
State_t=
\begin{cases}
s', & enter(s')\ge\theta_{in}\\
s, & exit(s)<\theta_{out}\\
UNKNOWN, & quality\ fails
\end{cases}
\quad \theta_{in}>\theta_{out}
\]

阈值、连续次数和窗口均为待校准参数，不是客观常数。必须与无滞回基线比较，
并检查状态延迟是否抵消噪声降低的收益。

## 6. 基础测量

### 6.1 自适应摆动点

从局部高点向下回撤超过 \(k_{swing}ATR\) 确认摆动高点；从局部低点向上反弹
超过同类阈值确认摆动低点。

设计依据：固定左右若干根 K 线的分形对不同波动环境不稳定。

适用条件：ATR 本身有效且当前不存在未处理缺口。验证时比较固定分形、ATR
摆动点和更简单均线斜率基线。

### 6.2 方向效率

\[
ER_{t,n}=
\frac{|C_t-C_{t-n}|}
{\sum_{i=t-n+1}^{t}|C_i-C_{i-1}|}
\]

- \(C_t\)：时点 \(t\) 的收盘价；
- \(n\)：回看窗口；
- ER 接近 1 表示净位移相对路径长度较高；
- ER 接近 0 表示往返较多。

ER 只测量方向效率，不能单独证明趋势会延续。

若分母为 0、任一输入非有限或历史不足，ER 返回带原因码
`UNKNOWN_ZERO_PATH_LENGTH` 或 `UNKNOWN_INVALID_INPUT`；不得输出 NaN、
无穷大或把未定义值强制设为 0，也不得用该值更新状态、假说或权限。

### 6.3 波动分位

\[
ATRpct_t =
\frac{\#\{i\in[t-n,t):ATR_i\le ATR_t\}}{n}
\]

使用历史分位而非绝对 ATR，使不同价格尺度可比较。窗口必须只含过去数据，
上市早期样本不足时输出 `UNKNOWN`。

### 6.4 相对成交量

\[
RVOL_t=\frac{V_t}{Median(V_{t-n:t-1})}
\]

成交量表示参与度，不直接表示买方或卖方获胜。若不同 venue 或合约单位不一致，
必须先归一化或分源使用。

若历史中位数小于等于 0、任一输入非有限、单位不可比或历史不足，RVOL 返回
`UNKNOWN_ZERO_OR_MISSING_BASE` 或 `UNKNOWN_INVALID_INPUT`；零成交量的当前柱
只有在来源明确记录且历史基准有效时才可作为数值 0。

### 6.5 收盘位置与实体效率

\[
CLV_t=\frac{2C_t-H_t-L_t}{H_t-L_t}
\]

\[
BodyEfficiency_t=\frac{|C_t-O_t|}{H_t-L_t}
\]

当 \(H_t=L_t\) 时二者为 `UNDEFINED`，不能除零或强制设为 0。量、波幅、实体、
收盘位置和后续延续必须联合解释；十字星只代表该测量窗口内实体较小。

### 6.6 RSI 条件化测量

RSI 记录四类特征：

- 数值；
- 在同品种、同周期、过去窗口内的分位；
- 斜率；
- 与价格的候选背离。

\[
RSIpct_t =
\frac{\#\{i\in[t-n,t):RSI_i\le RSI_t\}}{n}
\]

RSI 是观察触发器和条件特征，不是开仓许可。要检验其增量价值，至少比较：

1. 结构+位置基线；
2. 结构+位置+普通 RSI；
3. 结构+位置+状态条件化 RSI；
4. 去除 RSI 的完整系统。

## 7. 区域、结构位置与可交易性

关键位置必须表示为区间：

\[
width_t=\max(k_{atr}ATR_t,\ k_p P_t)
\]

- \(P_t\)：参考价格；
- \(k_{atr},k_p\)：待验证参数；
- 区域来源可包括历史摆动、趋势起点、成交密集/稀疏区、锚定 VWAP、缺口、
  多周期重合和事件价格中枢。

区间位置：

\[
Position_t=\frac{P_t-L_t}{U_t-L_t}
\]

当 \(U_t\le L_t\) 时区间无效。系统必须把“市场路径判断”与“当前位置是否具有
交易优势”分开。区间中部默认没有边缘优势，但是否设置硬性禁区属于待验证
决策假说。

区域强度不能只由触碰次数决定。每次触碰后必须记录反应幅度、持续时间、成交
压力、穿透深度、收回速度和后续延续。反弹越来越弱可能是支撑消耗；高卖压下
跌不动并快速收回可能是吸收候选。两者需要竞争，不能事后选故事。

## 8. 情绪与“参与者意图”的可观测边界

“恐慌、贪婪、饥渴、机构吸筹、散户逃离”等词只有在被拆成可观测代理变量后
才能进入模型。公开聚合行情通常不能识别具体人数、身份、开仓/平仓意图或未来
消息安排。

本项目把情绪拆成四类响应：

1. 压力：主动成交、订单流不平衡、价格速度；
2. 冲击：相对 ATR 的位移、跳跃、清算；
3. 韧性：冲击后的收回、延续失败、深度恢复；
4. 拥挤：持仓、资金费率、基差和跨市场相对强弱。

这些测量只能形成机制候选，例如“空头回补占比可能上升”，不能生成
“某机构将发布利好”的事实陈述。

## 9. 用户经验案例的抽象方法

用户提供的连续多日案例不是固定八日规则。它应被抽象为一个可变长度的
“冲击—压缩—响应—延续/失败”事件：

```text
背景下降或高压
→ 关键区出现高参与冲击
→ 价格推进与成交压力不一致
→ 后续窗口波动/成交压缩
→ 再扩张时选择延续、平衡或转换
→ 根据新证据淘汰或升级路径
```

从不同视角提出的竞争假说包括：

- `H-SCR-01`：卖压被吸收，形成阶段转换；
- `H-SCR-02`：只是空头回补或消息挤压，随后恢复下降；
- `H-SCR-03`：进入平衡区，无持续单边优势；
- `H-SCR-04`：支撑逐步消耗，最终进入流动性真空；
- `H-SCR-OTHER`：当前观测不足或存在未建模机制。

每个假说预测的是部分顺序关系，不要求固定发生在第几天。例：

\[
shock \prec compression \prec response \prec
\{continuation,\ balance,\ reversal,\ expiry\}
\]

验证时事件窗口由过去信息触发，不能看到结果后回选“最像”的起点和长度。

## 10. 假说竞争

### 10.1 三类假说

- 路径假说：同一窗口内尽量互斥，决定要准备哪类策略；
- 机制假说：可以共存，用于解释证据和设计后续区分测试；
- 交易假说：路径、位置、触发、成本、失效和风险的结合。

### 10.2 有限路径池

每个窗口最多：

- 1 个主导路径；
- 2 个替代路径；
- 1 个尾部风险路径；
- `OTHER/UNKNOWN`。

低证据假说不删除，进入 `QUEUED` 或 `DORMANT`。只有激活条件出现时才参与
当前排序。有限池的目的不是否认复杂性，而是防止无限叙事使系统无法行动。

### 10.3 测量合同

任何进入测试阶段的假说必须有：

- 唯一 ID 和版本；
- 类型与时间周期职责；
- 前提；
- 预测窗口；
- 预期部分顺序路径；
- 支持和反对证据；
- 硬反证条件；
- 过期规则；
- 交易链接或明确 `NONE`；
- 禁止交易条件；
- 依赖组；
- 下一项最便宜的区分测试；
- 结果历史。

缺少上述字段的内容可保留为研究线索，但不能进入回测或行动。
在 D3/E2 前，硬反证与过期规则还必须升级为版本化机器谓词，显式绑定
observable ID、运算符、阈值或区间、时钟、窗口、缺口/删失处理和终态枚举。
当前仅有自然语言规则的合同必须标记
`NOT_YET_EXECUTABLE_BLOCKS_D3_E2`，不能被解释为已经具备自动评分能力。

## 11. 证据更新与相关性治理

E0 阶段使用有序证据，不把分数解释为概率。每个相对独立的依赖组在一次更新
中最多贡献一次：

1. 结构；
2. 位置；
3. 量价与订单流；
4. 波动；
5. 杠杆与强制流；
6. 相对强弱与宏观；
7. 事件反应；
8. 数据质量。

E0 候选有序分数沿用当前核心理论的冻结组内聚合形式：

\[
Score_{h,t}=
\operatorname{clip}\left(
Score_{h,t-1}+
\sum_{g=1}^{G}A_g\{\tilde e_{i,h,t}\},
-Q,Q
\right)
\]

其中 \(e_{i,h,t}\in\{-2,-1,0,1,2\}\)。E0 不允许未登记的
`PriorOrdinal` 或 \(w_{h,g}\)；新实例从 0 开始。\(A_g\) 使用冻结的组内聚合器，
默认只保留绝对强度最大的一个增量，并以 `evidence_id` 稳定解决并列；单组贡献
上限和总上限 \(Q\) 必须绑定参数登记。该分数只用于排序候选。结构硬失效、
数据失败或权限失败优先于总分。

候选时间衰减：

\[
\tilde e_{h,g,t}=e_{h,g,t_0}\cdot
\exp\left(-\ln(2)\frac{t-t_0}{\tau_{1/2,g}}\right)
\]

半衰期 \(\tau_{1/2,g}\) 是待验证参数；经过一个半衰期后贡献恰好减半。
相反结构、来源修订、时段切换或重大事件可使证据立即失效，而不是仅缓慢衰减。

只有在冻结、互斥且覆盖充分的路径集合上，积累足够样本并完成样本外校准后，
才允许把模型输出映射为概率。未来可用：

\[
\operatorname{logit}P(H_h|E)=
\operatorname{logit}P(H_h)+
\sum_i \log
\frac{P(E_i|H_h)}{P(E_i|\neg H_h)}
\]

但相关证据不能被当作独立似然相乘。概率输出必须用 Brier score、log loss、
可靠性曲线和分层样本量验证；未校准前只报告 ordinal ranking。

## 12. 历史相似状态

相似性基于点时特征，而不是肉眼选择相似 K 线：

\[
X_t=[B,E,D,L,C,F,R,K,Z,ER,ATRpct,RSIpct,RVOL,Q]
\]

候选距离：

\[
d(X_i,X_t)=\sum_k w_k|z_{i,k}-z_{t,k}|
\]

权重、标准化和距离形式均需在开发集选择，并与简单同状态分组基线比较。结果
返回未来路径、收益、MFE、MAE、首次触及和持续时间的分布，不返回单一模板。

小样本比例必须收缩：

\[
\hat p=\frac{n p_{local}+\lambda p_{base}}{n+\lambda}
\]

- \(n\)：相似样本量；
- \(p_{local}\)：局部比例；
- \(p_{base}\)：更广泛状态的基准比例；
- \(\lambda\)：收缩强度。

样本选择、权重与 \(\lambda\) 都属于开发参数；历史相似性不能打开或选择
holdout。

## 13. 标签与验证

### 13.1 竞争风险/首次触及

对一个冻结交易假说，定义四类终点：

- 目标触及 `TARGET`；
- 结构失效 `STRUCTURE_STOP`；
- 风险止损 `RISK_STOP`；
- 时间到期 `TIMEOUT`。

\[
Y=\arg\min_{j\in J}T_j
\]

若同一不可分辨时间桶同时触及目标和止损，采用保守的 `STOP_FIRST`，或标记
`AMBIGUOUS` 后剔除；规则必须在看到结果前冻结。数据缺口跨越任一障碍时标记
`CENSORED_GAP`，不得推断先后顺序。

### 13.2 分层评价

状态层：

- 方向与阶段识别；
- 状态切换延迟；
- 未知/弃权比例；
- 转换假阳性。

假说层：

- Top-1、Top-2 和有限池覆盖；
- 硬反证响应；
- 生存时间与过期；
- 正确假说被错误淘汰；
- 概率校准（仅校准后）。

决策层：

- 触发后胜率；
- 每笔净期望值；
- 区间中部误交易；
- 无触发提前入场；
- WAIT 的机会成本。

执行层：

- 成交概率；
- 滑点、费用、资金费率；
- MFE、MAE、盈利捕获率；
- 重复、拒单、超时和未知订单。

## 14. 从市场路径到交易价值

路径概率与交易成功概率不同：

\[
P(H)\ne P(TradeSuccess\mid H,Trigger)
\]

提交订单前的净期望值候选为：

\[
EV_{submit}=
p_{fill}
\left[
\sum_j p_j R_j-C_{fill}
\right]
-(1-p_{fill})C_{no\_fill}
\]

- \(p_{fill}\)：成交概率；
- \(p_j\)：成交后结果 \(j\) 的条件概率；
- \(R_j\)：以账户风险或货币单位表示、尚未扣除本式执行成本的条件结果；
- \(C_{fill}\)：费用、滑点、资金费率和冲击；
- \(C_{no\_fill}\)：错失、撤单或不利选择成本。

\(j\) 必须来自版本化、互斥且完备的 `ActionOutcome` 分区，并满足
\(p_j\ge0\) 与 \(\sum_jp_j=1\)。`OTHER/UNKNOWN` 残差不得被删除；若分区证明、
概率归一化或样本外校准任一缺失，\(EV_{submit}\) 返回 `UNKNOWN`，只能进行
区间压力测试，不能产生行动许可。

这些概率在未校准阶段不能填入伪精确数值。E0/E2 前可使用区间、压力测试和
ordinal decision，不能声称真实 EV。

## 15. 入场、止损、目标与动态管理

### 15.1 入场区域

候选入场必须同时满足：

\[
EntryZone =
StatePermission
\cap StructuralZone
\cap TriggerZone
\cap DataPermission
\cap RiskPermission
\]

任一集合为空则 `WAIT`。RSI 触发只能贡献 `TriggerZone` 的一个条件。

### 15.2 结构止损与仓位

止损先定义假说失效位置，再加已冻结的波动缓冲：

\[
Stop=InvalidationLevel\pm k_{stop}ATR
\]

仓位沿用当前核心理论 v2.1 的研究候选几何：

\[
q=
\min\left(
\frac{R_{budget}}
{|P_{entry}-Stop|+Cost_{worst/unit}+Tail_{unit}},
Q_{liq},Q_{venue},Q_{margin}
\right)
\]

- \(R_{budget}\)：账户货币计价的最大损失预算；获授权后可由
  `Equity × RiskFraction` 产生；
- 分母三项全部必须归一到“账户货币/可执行单位”；
- \(Q_{liq},Q_{venue},Q_{margin}\) 全部必须是同一可执行数量单位；
- 合约乘数、报价/账户币种、汇率或费用单位无法闭合时，\(q\) 为 `UNKNOWN`。

这是对现行核心公式的引用，不是新的行动权限。在 P0 尚未获得真实账户风险、
执行或交易授权时，只能使用归一化 \(R\) 或合成账户做后续获授权的工程测试，
实际 `max_risk=0`。

### 15.3 持仓后单调风险约束

开仓后锁定原始假说和最坏允许风险。对多单：

\[
Stop_{t+1}\ge Stop_t
\]

对空单：

\[
Stop_{t+1}\le Stop_t
\]

管理动作只能保持、收紧止损、减仓或退出，禁止扩大最坏风险、亏损加仓或因
短期噪音重写理由。若要重新入场，必须创建新的交易假说和证据链。

目标可以随新信息调整，但必须通过“剩余净期望值”规则，且不能把已见收益
用于重新拟合目标。候选：

\[
Continue\ iff\ EV_{remaining}>EV_{exit}+Margin
\]

该规则本身必须与固定目标、分批目标和追踪止损基线比较。

## 16. 决策状态机

```text
数据或权限失败 → SUSPEND
高周期未知 → WAIT
不在可交易区域 → WAIT
存在候选但证据不足 → WATCH
接近区域但触发未完成 → PREPARE
触发、净价值和风险均通过 → EXECUTE
持仓存在 → MANAGE
失效、目标或到期 → EXIT
```

盘前或高周期收盘后生成有限路径池；盘中主要更新证据和执行预设动作。触发
完成后必须执行或明确放弃，不能无限增加新叙事。

## 17. 宏观、事件与跨市场层

宏观数据必须使用点时 vintage 和实际发布时间。事件层记录：

- 事件来源与版本；
- 计划/实际发布时间；
- 事件前价格；
- 事件异常收益和成交；
- 事件 VWAP；
- 1小时、4小时、1日持续性；
- 相对市场和行业表现；
- 修订与意外值。

相对收益候选：

\[
r^{rel}_{asset,t}=r_{asset,t}-\beta_t r_{benchmark,t}
\]

\(\beta_t\) 必须仅用过去窗口估计。宏观和新闻首先是风险/状态证据；在没有
稳定、可复现、点时可用事件数据前，不得作为精确入场信号。

## 18. 权威数据不能由来源名替代

数据可用性必须同时满足：

1. 来源权威：谁发布、是否为原始持有者或正式统计机构；
2. 文件完整性：校验和、字节身份、覆盖和断档；
3. 点时语义：当时何时可用；
4. 修订语义：是否会替换、补发或重分类；
5. 测量适配：字段能否真正测量目标变量；
6. 法律和许可：是否允许研究、存储和自动化使用；
7. 交叉验证：是否有独立来源或控制可检查。

因此，官方数据可以是 A 级来源但具有 `COVERAGE_UNKNOWN`；商业数据可以提供
更好覆盖但不因付费而自动成为 A 级。数据来源等级、完整性状态和研究证据
阶段必须分别报告。

## 19. 参数分类与假设值

参数分为：

- 物理/合约参数：tick size、合约乘数、费率规则；
- 测量参数：窗口、归一化、摆动阈值；
- 状态参数：滞回、状态边界；
- 决策参数：最低边缘、禁区、到期；
- 执行参数：延迟、成交、滑点、冲击；
- 风险参数：归一化风险约束，真实值需另行授权。

每个参数必须标记来源类型：

- `DIRECT_COMPUTATION`；
- `PRIMARY_LITERATURE`；
- `SAMPLE_ESTIMATE`；
- `INITIAL_VALIDATION_ASSUMPTION`；
- `SENSITIVITY_BOUND`；
- `UNSUPPORTED_PLACEHOLDER`。

初始值只能用于检查模型能否运行，不得描述为市场规律。每项至少测试低、
基准、高三档，并检查结论是否只在狭窄区间成立。

## 20. 假说失败后的修订纪律

回测不符合假说时，先冻结当前版本和所有负面证据，再按顺序诊断：

1. `DATA_AVAILABILITY`：样本、断档、时钟、修订是否合格；
2. `MEASUREMENT`：代理变量是否实际测量了理论对象；
3. `STATE`：状态边界或多周期衔接是否错误；
4. `MECHANISM_LIBRARY`：是否缺少竞争机制；
5. `PATH_SPEC`：预测路径、窗口或硬反证是否不合理；
6. `DEPENDENCE`：是否重复计算相关证据；
7. `CALIBRATION`：排序到概率或阈值映射是否失真；
8. `ACTION_GEOMETRY`：入场、止损、目标是否使正确观点变成差交易；
9. `COST_EXECUTION`：费用、成交、滑点或延迟是否吞噬边缘；
10. `PERMISSION_RISK`：数据/行动是否本就不应被允许。

每轮只允许一个主要理论变化：

```text
冻结旧版本
→ 指定主要错误类
→ 声明一个局部变化
→ 列出不变约束和预期可观测后果
→ 创建新版本
→ 使用新的开发/校准/未见窗口
→ 重复控制与敏感性测试
```

这实现“多提假设、多做验证、局部优化”，同时防止看到结果后不断改规则来
挽救理论。证据充分的硬反证可以终止一个具体版本，但不会物理删除其假说家族；
若更简单模型持续达到相同或更好结果，应优先简化。

## 21. 最小可验证模型顺序

为了降低成本和过拟合风险，研究按以下顺序增加复杂度：

1. 数据、PIT、修订和断档合同；
2. OHLCV/交易的简单状态与结构基线；
3. 只增加方向、位置和区域；
4. 增加 RSI 条件化并做消融；
5. 只有覆盖合格时增加订单流、OI、资金费率和强平；
6. 只有真实序列 L2 合格时验证冲击—韧性 \(R\)；
7. 最后增加事件、宏观、历史近邻和复杂机制；
8. 每一步都与更简单冻结基线比较。

复杂模型只有在样本外、成本后和敏感性下提供稳定增量价值时才保留。

## 22. 模块接口

| 模块 | 输入 | 输出 | 失败语义 |
| --- | --- | --- | --- |
| Data Authority | 来源文档、许可、原始身份 | source contract | `DENIED/UNKNOWN` |
| Raw Admission | 原始字节与外部权威 | immutable receipt | fail closed |
| PIT Replay | 已准入记录 | \(\mathcal I_l(\tau)\) | gap/censored |
| Feature | PIT 信息集 | typed measures | undefined/unknown |
| State | measures + quality | \(S_t\) | abstain |
| Zone | structure + volatility | interval zones | no valid zone |
| Hypothesis | state + zones | finite paths/mechanisms | OTHER/UNKNOWN |
| Evidence | new typed evidence | ordinal ranking | dependency reject |
| Decision | paths + trigger + value | state machine action | WAIT |
| Risk/Execution | allowed action | order plan/result | SUSPEND/EXIT |
| Evaluation | frozen inputs/results | metrics/error class | inconclusive |

任何模块不得越过下游权限，例如 State Engine 不能直接创建订单，回测结果也
不能自动授权 paper 或实盘。

## 23. 可证伪的核心研究问题

首批优先验证：

1. 多周期状态是否比简单单周期基线提供稳定增量信息；
2. 结构位置是否能减少区间中部的低价值交易；
3. RSI 条件化是否优于固定 30/70，或是否根本没有增量；
4. 压力—冲击—韧性是否能区分延续与吸收；
5. OI、资金费率和强平是否只提供机制解释，还是改善交易结果；
6. 有限竞争路径是否比单叙事或单方向分类更早淘汰错误路径；
7. 证据依赖去重是否改善校准并降低虚假置信；
8. 结构失效止损是否优于固定百分比；
9. 动态管理是否在成本后优于冻结退出基线；
10. 复杂系统是否优于简单趋势/区间/不交易基线。

若第 10 项长期不成立，合理结论是简化或停止，而不是无限增加变量。

## 24. 理论固定项与可优化项

固定项：

- 类型分层；
- PIT 和修订不可穿越；
- 假说可反证、可过期、可留档；
- 低周期不重写高周期；
- 评分不等于概率；
- 不满足触发不交易；
- 先定义结构失效，再算仓位；
- 持仓后不能扩大原定最坏风险；
- 构建、独立复核和阶段批准分权；
- 负面结果与失败版本永久可追踪。

可优化项：

- 周期组合；
- 摆动、ATR、ER、RSI、RVOL 窗口和阈值；
- 状态边界和滞回；
- 区域宽度和强度；
- 证据权重与衰减；
- 历史近邻距离；
- 路径先验和概率校准；
- 触发、止损、目标、时间止损；
- 成交、成本和最低净价值；
- 假说池数量，但不得删除 `OTHER/UNKNOWN`。

## 25. 结论

本候选把用户的经验分析方法转化为一个不依赖固定八日长度的系统方法论：

> 从多周期背景、结构位置、量价压力、冲击后的韧性、杠杆拥挤、事件反应和
> 数据质量出发，提前登记有限竞争路径；市场变化时更新的是证据和路径状态，
> 只有满足点时数据、结构触发、净价值、风险和权限后才行动。失败时首先诊断
> 失败发生在哪一层，以一个可归因变化产生新版本，而不是删除假说或事后重写
> 故事。

下一步不是宣称理论成立，而是冻结对象字典、假说队列、测量合同、参数区间和
数据权威标准，然后在后续独立授权的数据阶段按从简单到复杂的顺序验证。
